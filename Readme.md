## Git 贡献提交规范
- `feat:` 新功能的说明。
- `fix:` 修补 bug 的说明，可以是测试发现的 BUG、也可以是开发自己发现的 BUG。
- `docs:` 增加文档、注释，比如为代码添加、或删除注释、README, CHANGELOG, CONTRIBUTE等等。
- `style:`  调整代码格式（不影响任何代码逻辑的变动），比如代码行换行、缩进等对代码逻辑、编译、运行不产生影响的。
- `perf:` 性能优化，比如代码的性能优化、软件功能的性能优化等。
- `test:` 与测试相关，比如增加测试用例，包括单元测试、自动化测试、集成测试等。
- `chore:` 构建过程、或者增加依赖库、辅助工具的变动等，比如公司自动化构建、容器化部署。
- `refactor:` 重构（即不是新增功能，也不是修改 bug 的代码变动）。
- `revert:` 特殊情况，当前 commit 用于撤销以前的 commit。
